# ADR 004 — Місто детали — інформація, замовлення не дробиться

- **Статус:** прийнято.
- **Контекст:** два (далі N) пункти видачі — Запоріжжя та Дніпро; більшість покупців — самовивіз.
- **Рішення:** місто детали — інформаційний рядок («В наявності, Дніпро») на картці та сторінці товару. У чекауті один вибір пункту на все замовлення; якщо частина деталей в іншому пункті — одна інформаційна строка, замовлення не дробиться.
- **Відкинуто:** вибір міста як гілка сценарію; дроблення замовлення по пунктах — зайва складність для рідкого випадку.
