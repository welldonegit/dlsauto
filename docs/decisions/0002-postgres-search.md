# ADR 002 — Пошук на Postgres замість Meilisearch

- **Статус:** прийнято.
- **Контекст:** пошук — головний вхід (назва + авто, OEM, sku); обсяг ~1200 товарів; інфраструктура на одному VPS.
- **Рішення:** Postgres — `tsvector` по name+description (unaccent), `pg_trgm` GIN по нормалізованих name/OEM/sku. Автокомпліт з 3 символів, < 100 мс. Точний OEM/sku → редирект на товар.
- **Відкинуто:** Meilisearch / Elasticsearch — зайвий сервіс, пам'ять і супровід для такого обсягу; виграш не виправдовує складності.
