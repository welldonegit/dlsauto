# ADR 005 — Токени живуть у коді, DESIGN_TOKENS.md генерується

- **Статус:** прийнято.
- **Контекст:** експорт Claude Design — специфікація, не джерело; значення плавають і їх треба звести до канону, що використовується всюди.
- **Рішення:** єдине джерело правди — `src/app/globals.css` (`@theme`, Tailwind v4). `docs/DESIGN_TOKENS.md` генерується з нього (`scripts/export-tokens.ts`); CI падає при розбіжності. Компоненти — лише `var(--token)` / утиліти, прив'язані до токенів; літеральні px/hex у `src/components` заборонені (`scripts/check-no-literals.mjs`).
- **Відкинуто:** ручний MD як джерело токенів; значення в `tailwind.config` окремо від CSS; локальні px/hex у компонентах.
