# ADR 003 — VPS + Dokploy

- **Статус:** прийнято.
- **Контекст:** невеликий магазин, обмежений бюджет, дата-центр в Україні, потрібні БД + локальний диск медіа + фоновий воркер.
- **Рішення:** Hostpro NVMe VPS, Ubuntu; деплой через Dokploy (ветка `stage` → stage, `main` → прод, окремі БД/env). CI збирає образи в GHCR, сервер лише pull+run. Cloudflare — DNS/CDN/WAF.
- **Відкинуто:** managed PaaS (Vercel тощо) — не лягає Payload + воркер + локальний диск; Kubernetes — надмірно для одного вузла.
