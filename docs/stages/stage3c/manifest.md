# Этап 3c — карта страниц каталога

Карта «страница → URL → файлы экспорта → состояния». Детальный поэлементный
манифест каждой страницы добавляется **перед её вёрсткой** (отдельным разделом
ниже по мере работы), по циклу «манифест → вёрстка → сверка → коммит». URL — по
`DEV_CONTEXT §8`; где §8 не даёт URL — помечено ⚠️ и вынесено в «Развилки URL».

Источник правды по составу/виду — `docs/design-export/`. Бизнес-поведение, которого
нет на канвасе, — из `DEV_CONTEXT §5` и `CATALOG_PLAN` (Р-решения).

## Развилки URL (нет в §8 — вопрос владельцу, дефолт применяю)

- **A. `/catalog` корень.** §8 даёт `/catalog/<category>` и фильтры query, но не отдельный URL индекса категорий. **Дефолт:** `/catalog` = листинг **всех** товаров (`DLSCatalog` без категории, с фильтрами и сортировкой); сетка-индекс 9 категорий (`DLSCategoriesList`) уже есть на главной (`categoriesBlock`), отдельной страницей-индексом не делаю. Мега-меню «Усі категорії» → `/catalog`.
- **B. «Обране».** §8 не даёт URL. **Дефолт:** `/favorites` (noindex, §8 список).
- **C. «Порівняння».** §8 не даёт URL. **Дефолт:** `/compare` (noindex).
- **D. Марка vs Модель.** `/brand/<brand>` = карточки моделей марки (`DLSBrandIndex`-стиль), `/brand/<brand>/<model>` = листинг товаров модели (`DLSCatalog`, предустановленный фильтр). **Дефолт** подтверждается §8 (оба URL есть).
- **E. Фильтры-канонизация.** `?brand=&model=&sort=&price=&page=` — query; `canonical` на чистую `/catalog/<category>` (§8). Сортировка/пагинация — query, noindex не нужен (canonical достаточно).

## SEO / аналитика (на всех страницах, §8 + промпт)

- title/description — шаблоны из Payload (categories/products seo* + fallback), не из кода; canonical; hreflang uk/ru/x-default.
- JSON-LD: `BreadcrumbList` везде; `Product`+`Offer` (цена, availability по статусу) на товаре.
- dataLayer: `view_item_list` (листинги), `select_item`, `view_item` (товар), `add_to_wishlist`, `add_to_compare`.
- Проданные — 200 со статусом «Продано» (§8).

## Порядок работы (Part Б)

Каждая страница: манифест из экспорта (элементы, количество, пропорции, шрифты,
цвета, поведение) → вёрстка (Server Components по умолчанию; ширина — только
`<Container>`; ленты — `.dls-rail`) → сверка 390 / 1280 / 1536 / 1920 рядом с
экспортом (два списка расхождений пустые) → коммит. Правила подбора (матрица
расположения, broad→OEM, пары/комплекты, фолбэк донора) — в `src/lib/rules` с
unit-тестами (приёмка §3) до страниц, которые их используют.

Предлагаемая очерёдность: карточка-листинг инфраструктура (data-layer запросы
каталога, фильтры) → Каталог (№1) → Модель/Марка (№3–4) → Товар (№5) + правила
подбора (5a) → Обране (№6) → Порівняння (№7).

## Манифест: Каталог (`DLSCatalog`)

Шрифт Golos Text; фон `#F6F6F6`; текст `#1E232B`, второстепенный `#4A5260`/`#6B7380`;
акцент `#E0001B`; границы `#E6E9EE`. Ширина — `<Container>` (в экспорте 1312; у нас
1376, боковые 16/32). Состав сверху вниз:

1. **Хлебные крошки** Головна / Каталог (14/20, `#4A5260`→`#1E232B`).
2. **H1** «Каталог запчастин» (desktop 40 / tablet-laptop 32 / mobile 28, 600, ls −0.02em). Строка «Показуємо деталі на **{авто}**» (15/22) — когда выбрано авто (cookie).
3. **Рейл категорий** (`DLSCategoryCard`): карточки 200px (160 mobile), фото + название + «N деталей». Desktop/laptop — grid 5/4 колонок; tablet/mobile — горизонтальный скролл (`.dls-rail`). Клик → фильтр по категории + скролл к товарам.
4. **Листинг** — 2 колонки `[aside фильтры | товары]` (на tablet/mobile aside → drawer/sheet по кнопке «Фільтри» со счётчиком).
   - **Aside** (sticky, radius 16, border `#E6E9EE`, pad 16): «Фільтри» + «Скинути». Аккордеоны (grid-rows 0fr→1fr): **Авто** (селекты Марка→Модель каскадом), **Категорія** (чекбоксы + счётчики), **Ціна** (інпути від/до + range-slider 100–120 000 ₴, нелинейный √), затем группы-чекбоксы.
   - **Toolbar**: кнопка «Фільтри» (panelMode) + чипы активных фильтров (removable) + сортировка (За популярністю / Спочатку нові / дешевші / дорожчі).
   - **Сетка товаров** `DLSProductCard`: desktop 4 / laptop 3 / tablet-mobile 2 кол; row-gap 48, col-gap 24 (12 mobile); кросс-фейд при смене фильтра.
   - **Пагинация**: «Показати ще N» (+20) + «Показано N із M».
   - **Пусто**: иконка-лупа + «За цими фільтрами нічого немає» + подсказка + «Скинути фільтри» / «Запитати менеджера».

**Фильтры vs модель данных — конфликты экспорта и `DEV_CONTEXT` (дефолты применены, флаг владельцу):**
- **«Перевірка»** (На стенді / На авто / Візуальний огляд) — это *метод проверки*, поле `checkMethod` **снято в Р14**. Дефолт: группа заменена на **«Стан»** (`conditionLabel`: Б/в, перевірений / Б/в / Б/в, з дефектами / Новий) — реальные данные, тот же слот.
- **«Гарантія»** (14/30/60) → `warrantyDays` ✅. **«Сторона»** (Ліва/Права) → `position` (ось side) ✅.
- **«Додатково»**: «Акція» → `discountPercent > 0` ✅; «З відео перевірки» — нет запрашиваемого поля (видео = mp4 в `photos`, не фильтруется в SQL). Дефолт: **убрано** из «Додатково» (осталась «Акція»); добавить при появлении флага/поля.

Поведение (из `<script>`): фильтры URL-driven (query, §8), сервер-рендер листинга + фасетные счётчики в data-layer; клиентский остров пушит query; «Показати ще» — рост `shown`; canonical на чистую `/catalog/<category>`. Авто — из cookie `dls_car` (fit-плашка на карточках). Проданные в каталог не попадают (§5).

**Сверка (390 / 1280 / 1536 / 1920, uk):** структура, рейл 9 категорий, аside-фильтры, тулбар, сетка (4/3/2 кол), «Показати ще N / Показано N із M», пустое состояние, мобильный sheet (скрыт, открывается кнопкой — проверено computed-style) — совпадают; 0 console-errors; 200.
- **Є в експорті, інакше у мене** (дефолты, подтвердить): (1) группа «Перевірка» → «Стан» (Р14); (2) «З відео перевірки» убрано (нет поля); (3) range-slider — трек + заливка без перетягуваних ручок (диапазон задаётся інпутами від/до) — закрыть ручки в доводке; (4) анимация смены фильтра — навигация вместо кросс-фейда (URL-driven ради SEO/§8); (5) авто-предфильтр: баннер показывается при фильтре Марка+Модель, cookie-авто даёт лише fit-плашки (не хард-фильтр).
