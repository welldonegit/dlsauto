# Этап 3c — карта страниц каталога

Карта «страница → URL → файлы экспорта → состояния». Детальный поэлементный
манифест каждой страницы добавляется **перед её вёрсткой** (отдельным разделом
ниже по мере работы), по циклу «манифест → вёрстка → сверка → коммит». URL — по
`DEV_CONTEXT §8`; где §8 не даёт URL — помечено ⚠️ и вынесено в «Развилки URL».

Источник правды по составу/виду — `docs/design-export/`. Бизнес-поведение, которого
нет на канвасе, — из `DEV_CONTEXT §5` и `CATALOG_PLAN` (Р-решения).

## Развилки URL (нет в §8 — вопрос владельцу, дефолт применяю)

- **A. `/catalog` корень.** §8 даёт `/catalog/<category>` и фильтры query, но не отдельный URL индекса категорий. **Дефолт:** `/catalog` = листинг **всех** товаров (`DLSCatalog` без категории, с фильтрами и сортировкой); сетка-индекс 9 категорий (`DLSCategoriesList`) уже есть на главной (`categoriesBlock`), отдельной страницей-индексом не делаю. Мега-меню «Усі категорії» → `/catalog`.
- **B. «Обране».** §8 не даёт URL. **Дефолт:** `/favorites` (noindex, §8 список).
- **C. «Порівняння».** §8 не даёт URL. **Дефолт:** `/compare` (noindex).
- **D. Марка vs Модель.** `/brand/<brand>` = карточки моделей марки (`DLSBrandIndex`-стиль), `/brand/<brand>/<model>` = листинг товаров модели (`DLSCatalog`, предустановленный фильтр). **Дефолт** подтверждается §8 (оба URL есть).
- **E. Фильтры-канонизация.** `?brand=&model=&sort=&price=&page=` — query; `canonical` на чистую `/catalog/<category>` (§8). Сортировка/пагинация — query, noindex не нужен (canonical достаточно).

## SEO / аналитика (на всех страницах, §8 + промпт)

- title/description — шаблоны из Payload (categories/products seo* + fallback), не из кода; canonical; hreflang uk/ru/x-default.
- JSON-LD: `BreadcrumbList` везде; `Product`+`Offer` (цена, availability по статусу) на товаре.
- dataLayer: `view_item_list` (листинги), `select_item`, `view_item` (товар), `add_to_wishlist`, `add_to_compare`.
- Проданные — 200 со статусом «Продано» (§8).

## Порядок работы (Part Б)

Каждая страница: манифест из экспорта (элементы, количество, пропорции, шрифты,
цвета, поведение) → вёрстка (Server Components по умолчанию; ширина — только
`<Container>`; ленты — `.dls-rail`) → сверка 390 / 1280 / 1536 / 1920 рядом с
экспортом (два списка расхождений пустые) → коммит. Правила подбора (матрица
расположения, broad→OEM, пары/комплекты, фолбэк донора) — в `src/lib/rules` с
unit-тестами (приёмка §3) до страниц, которые их используют.

Предлагаемая очерёдность: карточка-листинг инфраструктура (data-layer запросы
каталога, фильтры) → Каталог (№1) → Модель/Марка (№3–4) → Товар (№5) + правила
подбора (5a) → Обране (№6) → Порівняння (№7).
