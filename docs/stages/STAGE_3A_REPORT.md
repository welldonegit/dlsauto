# Етап 3a — звіт

Статичні сторінки: **404, Публічна оферта, Політика конфіденційності, Про компанію**. Метод — як на «Контактах»: значення лише токенами, структуру не змінюємо, нові компоненти — у `src/components`, без літеральних px/hex (CI `check:literals`). Контент — з Payload (блоки/richText, seed). Сверка — `pnpm design:compare:3a` (1280/390), знімки в `docs/stages/stage3a/compare/`.

## Зроблено

### Інфраструктура сторінок
- **`[...slug]` catch-all** (`src/app/(frontend)/[locale]/[...slug]/page.tsx`): CMS-сторінки за slug; відсутня/неопублікована → справжній 404. Сторінка з єдиним блоком `richText` → юридичний лейаут, інакше — `BlockRenderer`.
- **`BlockRenderer`** — реєстр блоків; порожній блок не рендериться; нереалізований тип — тихий плейсхолдер (тільки dev).
- **Мета** (`src/lib/meta.ts`): title/description з seo-полів з fallback-шаблоном, `metadataBase` з DOMAIN, canonical + hreflang uk/ru/x-default, `BreadcrumbList` JSON-LD. Заголовок сторінки тепер на самій сторінці (home/catch-all), layout дає лише `metadataBase` і `title.default` (= заголовок 404, бо not-found не має свого metadata).
- **Токени**: `--color-neutral-hero` (#16141A, фон першого екрана «Про компанію»), `--color-primary-light` (#FF5C6C, підсвічування диска), `--font-mono` (JetBrains Mono — mono-бирки 404 і «Шлях деталі»). `DESIGN_TOKENS.md` перегенеровано.
- **middleware** віддає локаль заголовком `x-dls-locale` (not-found не отримує params).

### 404 (`not-found.tsx`)
Справжній HTTP 404. Лінійний пікап без лівої фари (SVG тим самим штрихом, що набір іконок), self-draw на `stroke-dashoffset`, поважає `prefers-reduced-motion`. Пошукове поле (→ `/search`), корисні посилання, mono-бирка «404 · відсутня». Тексти uk/ru — зі словника i18n; `noindex`. Рендериться для будь-якої невідповідної адреси під локаллю.

### Оферта + Політика
Спільний лейаут `LegalPage`: хлібні крихти, H1, дата «Оновлено», **sticky-зміст зліва** + richText справа, по секції на кожен H2; на мобайлі зміст — аккордеон, scroll-spy через IntersectionObserver. `RichText` — серіалізатор Lexical у типографіку токенів (заголовки, абзаци, списки, посилання, інлайн-розмітка). Реквізити ФОП (з settings) — лише на Оферті.

### Про компанію (блоки, порядок за PROJECT_CONTEXT §5)
- **aboutHero** — диск ідеальними колами в SVG (вентиляційні прорізи + 5 отворів), нахил `perspective`+`rotateX`, обертання `rotateZ` ~24 с через Web Animations API; свічення/кільця — окремі нерухомі розмиті шари, у диску, що крутиться, жодного filter. Стоп поза вьюпортом (IntersectionObserver) і при reduced-motion.
- **stats v2 (виріз)** — 4 картки чорні/червоні через одну, виріз із лінійним гліфом, count-up при появі, hover-мікроанімації (тільки transform). Переіспользуваний (піде на головну).
- **whyDisassembly** — нумеровані 01–03 на `StepHeading`.
- **partPath** — скрол-керований закріплений сюжет: биту авто → розбирання → перевірка → позначення дефектів → картка товару → відправка. Сцена — лінійний арт у коді (як диск), тексти кроків — з CMS. Тільки transform/opacity (+ dash-draw маркерів).
- **team** — фото цеху + сітка фото; підписи — з `alt` медіа (ролі, без вигаданих імен — у моделі немає полів на людину).
- **whatElseWeDo** — `RotatingCardSlot` (2 послуги, автозміна 7 с, пауза на hover / поза вьюпортом / reduced, кросфейд + прогрес-крапки, клавіатура) + `VideoCard` → `VideoModal` 16:9 (Esc, повернення фокуса, блок скролу).
- **reviews** — опубліковані відгуки з колекції + середня оцінка (`getReviews`).
- **ctaText** — primary-картка із заголовком, що «проявляється» по словах.
- Нові примітиви: `MediaImage`, `Stars`; keyframes hover-карток у `globals.css`.

### `/ui`
Додано секцію «Етап 3a»: `Stars` (0–5), типографіка `RichText`; складені блоки (у русі) — на `/about`, юридична типографіка — на `/policy`/`/oferta`, 404 — на будь-якій неіснуючій адресі.

### Seed
Політика — реальний текст з експорту структурованим Lexical. Оферта — структура з **чернетковим текстом-плейсхолдером** (узгодження з власником). `about` — порядок за §5 + `whatElseWeDo` (картки, cex-відео), 6 кроків `partPath`, фото команди з ролями-alt.

## Сверка з експортом (0 багів)

- **Політика**: в експорті зміст закодований, але не відрендерений (одноколонка). Промпт і PROJECT_CONTEXT §5 вимагають sticky-зміст — зроблено за ними (стилі зносок — з мертвого коду експорту); узгоджене структурне доповнення, не баг.
- **«Про компанію»**: експорт основної сторінки не містить `whyDisassembly` і ставить «Що ще ми робимо» перед «Командою»; зроблено за **порядком PROJECT_CONTEXT §5** (включає whyDisassembly). «Що ще ми робимо» — нова версія (слот + відео, `DLSServicesVideo`), а не стара `DLSServicesWide`, як і описано в промпті.
- **Диск / stats / partPath / whatElse / reviews / cta** — 1:1 геометрія і хореографія з відповідних експортів; кольори зведено на токени (rgba-градієнти як літерали — дозволено `check:literals`).

## Значення поза шкалою / свідомі рішення

- H1 404 і диска зведено до `text-d` (56) на десктопі замість 64 експорту (>2px, як правило відступів 96/64).
- Велика цифра stats — `text-d`/`text-40` замість 76/64/40 (поза шкалою 56…11).
- Непіксельні розміри поза шкалою (картка 600px, іконка-бирка, обведення крапок) — у `rem` (дозволено `check:literals`), не як px-літерали.
- Декоративні градієнти/свічення — `rgba()`-літерали (точні значення експорту; токенів на кожен стоп немає).

## Не зроблено і чому

- **Блок «Поки ви тут» на 404** (`DLSNewArrivals`) — переіспользуваний блок головної з картками товарів; каталог/картки — етап 4. Пропущено.
- **Живі підказки пошуку** на 404 — потребують реального пошуку (етап 4) або вигаданих даних (заборонено). Поле є, підказки — пізніше.
- **Текст Оферти** — чернетка-плейсхолдер; юридичне формулювання чекає власника/юриста (відкрите питання).
- **Форма «Залишити відгук» / «Усі відгуки»** — відправка відгуків і сторінка-список поза scope 3a (як форма «Контактів» у етапі 1 — запис не підключений). Блок reviews лише читає.
- **i18n UI-хрому** (хедер/футер) — лишилось як у етапах 1–2 (бэклог); контент сторінок локалізований (ru з fallback на uk).
- **Імена команди** — модель `team` не має полів на людину; показуємо фото + роль з alt, імена не вигадуємо.

## Що перевірити руками

1. `docker compose up -d` → `pnpm db:migrate` → `pnpm db:seed`; `pnpm dev`.
2. `/about` на 1280 і 390: диск крутиться; у DevTools Performance 5 с запису — лише Composite від обертання (критерій 2). Скрол через «Шлях деталі» прокручує сюжет; слот «Що ще ми робимо» міняється сам, пауза на hover; відео відкриває модалку (Esc/клік-поза — закриває).
3. Клавіатура: Tab по крапках слота і по кнопці відео; Enter відкриває модалку; Esc закриває; фокус повертається.
4. `/policy` і `/oferta`: sticky-зміст підсвічує активну секцію; на 390 — аккордеон. Оферта показує реквізити ФОП.
5. Неіснуюча адреса (`/xxx` і `/ru/xxx`) → брендований 404, статус 404, `noindex`, свій текст ru.
6. `reduced-motion`: диск і слот стоять, лічильники миттєві.
7. `pnpm test` (23), `pnpm typecheck`, `pnpm lint`, `pnpm check:literals`, `pnpm build` — зелені.
8. `pnpm build && pnpm start` → `pnpm lighthouse http://localhost:3000/about …` (прод-збірка; dev-режим не показовий).

> Примітка: після зовнішнього `db:seed` перезапускати dev через `pnpm devsafe` (інвалідація `unstable_cache`, ADR 006). `pnpm devsafe` чистить `.next` — перед `pnpm start` потрібен свіжий `pnpm build`.
