**Решения владельца по фильтрам «Каталога» (23.11) — подтверждены, внесены фиксом:**

1. **«Перевірка» → «Стан».** ✅ Группа метода проверки (`checkMethod` снят в Р14) заменена
   на «Стан» (`conditionLabel`: Б/в, перевірений / Б/в / Б/в, з дефектами / Новий).
2. **«З відео перевірки» — возвращена.** ✅ Признак вычисляется (видео `video/mp4` среди
   `photos`, mimeType читается в base-проходе `getCatalog` — проверено: `select:{photos}`
   + `depth:1` отдаёт `mimeType`), **нового поля нет**; фильтр через `id in {videoIds}`;
   фасет скрыт, если ни у одного товара нет видео (`hasVideo`). В текущем сиде видео нет →
   фасет скрыт (ожидаемо); `?vid=1` даёт пустое состояние.
3. **Range-slider — ручки доделаны.** ✅ Две перетягувані ручки `role="slider"` (drag +
   клавіатура ↑↓←→, √-маппінг `vOf`/`tOf`, крок 2 %, мін. зазор 100 ₴, snap 100 ₴) — точно
   по экспорту. Drag коммитит `?pmax=…` на pointerup (через `valRef`, чтобы commit не ловил
   устаревшее значение; pointermove — continuous-приоритет). Проверено Playwright.
4. **Авто-предфильтр как в экспорте.** ✅ cookie `dls_car` хард-фильтрует листинг по модели
   (когда в URL нет явного Авто-фильтра и нет opt-out); баннер «Показуємо деталі на {авто}»
   с **«Змінити» / «Скинути»**; `?car=off` — opt-out (полный каталог, баннер скрыт); canonical
   не меняется; чтение cookie делает рендер динамическим (не кэшируется под чужое авто). Авто
   из cookie пред-заполняет селекты Марка/Модель (как экспорт из localStorage).
   ⚠️ **«Змінити»/«Скинути» в баннере — нет в `DLSCatalog`** (там только текст); добавлено по
   этому решению. «Змінити» открывает фильтр Авто (sheet <1024 / скролл к aside ≥1024),
   «Скинути» → `?car=off`. Помечено в manifest «Є у мене, нема в експорті» — подтвердить в финале.
5. **URL-навигация вместо кросс-фейда при смене фильтра.** ✅ Ради SEO/§8 (каждое состояние
   индексируется) — вместо анимации кросс-фейда экспорта.
