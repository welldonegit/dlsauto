## Решения по умолчанию — подтверждены владельцем (23.11)

Все пункты ниже владелец подтвердил. Исходные формулировки оставлены для истории.

1. **Great Wall — без лого.** ✅ В экспорте нет ассета лого Great Wall (16 лого на 17 марок). Марка засеяна (CATALOG_PLAN Р12 «Great Wall остаётся»), но **исключена из чипов home-modelsPicker** — чтобы сохранить экспортный ряд 16 лого (8×2). В каталоге/мега-меню остаётся.
2. **`position` — 13 значений.** ✅ Список «Розташування» синхронизирован с шаблоном v3 / справочником: `комплект: ліва + права` (`pair`) и `підходить на обидві сторони` (`both`) — разные fit-правила (Р36). Лейбл `pair` приведён к источнику — «комплект: ліва + права» (было «пара (ліва + права)»). ⚠️ Обновлённый `DLSAuto_dovidnyk_typiv.xlsx` (13 значень) в рабочем дереве **не появился** (там версия 21.11 с 12 значеннями); 13-значный список взят из `DLSAuto_tovary_shablon_v3.xlsx` «Списки» (идентичен). Файл справочника коммитну, как только он будет в дереве.
3. **Поле `products.inReserve`** (int) добавлено. ✅ §5 различает «Заброньовано»/«Продано» по `in_reserve`, но §4 поле не перечисляло (из KeyCRM-вебхука на этапе 6).
4. **bodyType моделей** проставлен по классу авто (Transporter/Crafter/Caddy/307 → `passenger`; пикапы/внедорожники — соответственно). ✅ Используется только для секций «на пікапи/позашляховики».
