# Этап 3a — статические страницы: 404, Оферта, Політика, Про компанію

Прочитай CLAUDE.md, docs/DEV_CONTEXT.md, docs/PROJECT_CONTEXT.md (§2–3, §5), docs/stages/STAGE_1_PROMPT.md (шаг 3 — правила разметки действуют целиком), STAGE_1_REPORT.md и STAGE_2_REPORT.md. Экспорт страниц — в docs/design-export/.

Метод тот же, что на «Контакти»: расхождение с экспортом не больше 2px, структуру не менять, значения — только токенами, новые компоненты — в `src/components/`, никаких локальных стилей. Контент — из Payload (pages с блоками, seed уже есть), не хардкодом. Остановка одна — в конце. Вопросы — пакетом, на развилках.

Порядок — по нарастанию сложности, каждая страница — отдельный коммит с Playwright-сверкой 1280/390:

## 1. 404
Страница из экспорта: линейный пикап (SVG-компонент, тот же штрих, что у набора иконок), текст, поиск, ссылки. Статус 404 реальный (`not-found.tsx`), для `/ru` — свой текст.

## 2. Оферта и Політика конфіденційності
Одна структура на две страницы: sticky-содержание слева, текст справа, якоря на разделы. Текст — richText-блок из Payload; реквизиты ФОП — из settings, выводятся на оферте. Длинный richText рендерить компонентом `RichText` с типографикой из токенов (заголовки, списки, таблицы, ссылки).

## 3. Про компанію
Блоки по PROJECT_CONTEXT §5 «Про компанію», рендер через `BlockRenderer` из этапа 2 — заглушки заменяются настоящими компонентами:
- **aboutHero** — тёмный первый экран. Диск: идеальные окружности в SVG с вентиляционными прорезями и 5 отверстиями; наклон — CSS `perspective` + `rotateX` на контейнере; вращение — `rotateZ` ~24 с/оборот на внутреннем элементе; свечение — отдельный неподвижный слой; в SVG, который вращается, никаких filter/blur; `will-change: transform`; остановка вне вьюпорта (IntersectionObserver) и при `prefers-reduced-motion`. Проверь в DevTools Performance: при вращении меняется только transform одного слоя.
- **stats** — «DLSAuto в цифрах» v2 (4 карточки в шахматном порядке, вырез сверху с иконкой, hover-анимации). Это тот же компонент, что пойдёт на главную — делай переиспользуемым, тексты из блока.
- **whyDisassembly** — нумерованные пункты 01–03 (компонент `SectionHeading` с шагом уже есть).
- **partPath** — «Шлях деталі», анимация только transform/opacity.
- **team** — «Команда і цех» (фото — плейсхолдеры из экспорта).
- **whatElseWeDo** — шапка H2 слева + текст справа; ниже две карточки 1:2 высотой 600px: слева `RotatingCardSlot` (две послуги, автосмена 7 с, пауза на hover и вне вьюпорта, кроссфейд + лёгкий масштаб фото + подпись с задержкой, индикатор прогресса в зоне подписи, клик переключает, при reduced-motion без автосмены), справа `VideoCard` (постер cover, play по центру, клик — `VideoModal` 16:9 на тёмном фоне, подпись как у соседней карточки).
- **reviews** — список отзывов из коллекции reviews (только published), средняя оценка.
- **ctaText** — текстовый CTA.

Пустой блок не рендерится. Тексты «в одному дворі в Запоріжжі» — как в seed (плейсхолдер, помечен в PROJECT_CONTEXT).

## 4. Общее для всех страниц
- Хедер и футер — те же компоненты, без копий.
- Мета: title/description из полей страницы с fallback-шаблонами, `metadataBase` из DOMAIN, canonical, hreflang uk/ru + x-default, BreadcrumbList для внутренних страниц. 404 — `noindex`.
- Страницы `/ru/...` — полноценные, контент из ru-полей с fallback на uk.
- Lighthouse mobile на каждой странице ≥ 90 по Performance и Accessibility (локально, через `pnpm lighthouse <url>` — добавь скрипт).

## 5. Критерии приёмки
- 4 страницы (6 с учётом /ru) открываются на stage-сборке и из seed-данных; Playwright-сверка с экспортом: 0 багов, унификация только из утверждённого маппинга этапа 1.
- Диск на «Про компанію» вращается без просадок: в Performance-записи 5 секунд нет Layout/Paint от вращения, только Composite.
- Слот карточек и видео-модалка работают с клавиатуры (Tab, Enter, Esc).
- Новые компоненты добавлены на `/ui` во всех состояниях.
- `pnpm test`, typecheck, lint, build — зелёные.
