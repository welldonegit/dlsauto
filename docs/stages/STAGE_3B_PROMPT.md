# Этап 3b — Головна

Прочитай CLAUDE.md, docs/DEV_CONTEXT.md, отчёты этапов 1–3a. Страница «Головна-B» — в docs/design-export/. Это источник правды по составу, порядку, виду и поведению блоков. PROJECT_CONTEXT.md — только для данных, текстов и поведения, которого в экспорте не видно (откуда берутся товары, что считается автоматически).

## Правила — урок этапа 3a
1. Что на странице и как оно выглядит — решает экспорт. Ничего не добавлять и не убирать: ни блоков, ни иконок, ни кнопок, ни индикаторов, ни анимаций, ни фото. Нет в экспорте — нет в коде; есть в экспорте — есть в коде.
2. Экспорт расходится с документами (блок описан, но его нет; порядок другой; элементов больше/меньше) — вопрос мне, пакетом, до начала блока. Самому не выбирать.
3. Перед каждым блоком — манифест из экспорта в `docs/stages/stage3b/manifest.md`: элементы, их количество, пропорции изображений, замеренные из computed styles размеры шрифтов, цвета, высоты карточек, отступы. Шрифты и цвета — как есть; шкала — только к отступам, радиусам, высотам контролов, в пределах 2px.
4. После блока — сверка по манифесту: счёт элементов, пропорции, pixel-diff 1280/390 (Playwright `toHaveScreenshot` с порогом). В отчёте по каждому блоку два списка: «есть в экспорте, нет у меня» / «есть у меня, нет в экспорте» — оба пустые.
5. Расхождение с экспортом ≤ 2px, структуру не менять, значения — токенами, компоненты — общие, контент — из Payload. Остановка одна — в конце. Вопросы — пакетом.

## Что делать
- Собрать `/` по странице «Головна-B» — это и есть главная. Страницу «Головна» (вариант A) не делать и не смотреть. Блок за блоком, в порядке экспорта, каждый блок — коммит со сверкой.
- Компоненты, которые здесь появляются впервые (карточка товара, мега-меню, чип модели, плитка бренда, карточка модели и т. д.), делать общими в `src/components/` со всеми состояниями, которые есть в экспорте — они пойдут в каталог и товар. Все — на `/ui`.
- Данные — из Payload через `src/lib/data`: марки, модели, категории с partsCount; товары по правилам DEV_CONTEXT §5 (новинки — 15 самых новых in_stock + ручное закрепление; пикапы/внедорожники — по bodyType + закрепление; «Сьогодні/Завтра» — из `src/lib/rules`). Отзывы — из reviews. Тексты блоков — из pages.
- Поведение, которого в экспорте не видно, — из PROJECT_CONTEXT §3–4: зависимые селекты марка → модель → категория, переключение марок без изменения высоты блока, пунктирная «Усі моделі» только при >3 моделях, формы слова «деталь/деталі/деталей», метка «Підходить на ваше авто» по cookie выбранного авто, избранное и сравнение в localStorage с бейджами в хедере.
- Ссылки в каталог и товар — реальные URL по DEV_CONTEXT §8, страницы появятся в 3c.
- Мета, hreflang, Organization + FAQPage schema.org; `dataLayer`-события `view_item_list`, `select_item`, `add_to_wishlist`; Lighthouse mobile ≥ 90 (видео lazy, `next/image` с sizes, мега-меню и модалки — динамический импорт).

## Отложено, не делать
Автокомплит поиска и подсказки (этап 4) — поле и debounce есть, запрос в заглушку. Корзина и «В кошик» (этап 5) — кнопка есть, по клику тост «Кошик — етап 5». Страницы каталога и товара (3c).

## Критерии приёмки
`/` на seed-данных; сверка по манифестам — оба списка расхождений пусты по каждому блоку; переключение марок не меняет высоту блока; избранное/сравнение/выбранное авто переживают перезагрузку; мега-меню и модалки работают с клавиатуры; test/typecheck/lint/literals/tokens/build зелёные.
