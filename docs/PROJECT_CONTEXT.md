## 1. О проекте

**Что:** интернет-магазин б/у автозапчастей с собственной разборки. Клиент — DLSAuto, **Запоріжжя** + пункт выдачи в **Дніпрі** (что это — склад или вторая разборка — уточняется). Продают через Prom.ua, avto.pro, OLX. Услуги: выкуп авто на разборку, пригон авто, собственное СТО.

**Языки:** украинский — основной, русский — второй (`/ru`). Макеты — на украинском. Чат — на языке пользователя.

**Специализация:** основа — пикапы и внедорожники, есть и легковые. 15–16 марок (на канвасе 16 после разделения Peugeot и Fiat), число поколений больше 26 — точное у клиента. ~1200 деталей. Лидеры: Mitsubishi 260, Ford 226, Mazda 226, Nissan 172.

**Аудитория:** розница + СТО. Большинство — самовывоз. Один телефон на все вопросы.

**Особенности для дизайна:**
- Каждая деталь в одном экземпляре → нигде нет счётчиков количества; есть состояние «Продано». Проданные страницы живут.
- Проверка на стенде/авто, дефекты обведены белым маркером, фото реальной детали.
- Главное возражение — предоплата. Главный вопрос — «подойдёт ли».
- Кабинета нет. Избранное, сравнение, история просмотров — localStorage; выбранное авто — cookie.
- Как ищут: по названию детали + авто, по OEM-номеру, «всё с моей машины». Поиск — главный вход, категории плоские (один уровень), страница модели — витрина.
- Совместимость — по модели-донору (и близнецу), без TecDoc. «Підходить на ваше авто» = деталь с модели, которую выбрал покупатель.
- Город детали — информация («В наявності, Дніпро»), а не ветка сценария: выбора города нет, заказ не дробится.
- Тип кузова в интерфейсе не показывается (тот, кто ищет по модели, знает свой кузов). Живёт только как признак в админке для секций «на пікапи» / «на позашляховики».

**Факты для текстов:** 5000+ заказов/год, 4+ года, 1200+ деталей, ~48 отзывов на Prom (4.8), 100 % деталей проверены. Отправка в день заказа при подтверждении до 15:00 (НП, Delivery), габаритные 1–2 дня, по Запорожью доставка в бокс для СТО (про Днепр — уточнить). Гарантия 14 / 30 (двигатели, КПП, агрегаты) / до 60 (восстановленные). Не возвращаются режущиеся части кузова. Оплата: карта онлайн (monoPay, Visa/MC, Apple/Google Pay), наличные при самовывозе, предоплата за габаритные. Мин. заказ 500 ₴. Бесплатной доставки нет.

**ОТКРЫТЫЕ ВОПРОСЫ КЛИЕНТУ:**
1. (критично) Отправляют ли мелкие детали наложенным платежом без предоплаты и какой % / сумма предоплаты за габаритные. Пока везде нейтральная формулировка «Карткою онлайн або готівкою при самовивозі. Для габаритних — передплата після підтвердження».
2. Днепр: склад или вторая разборка; адрес, график; перевозят ли детали между пунктами и за сколько (от этого — одна строка в чекауте).
3. Полный список категорий с количеством деталей; топ-10 деталей по продажам (для чипов «Часто шукають»).
4. Точное число поколений (для карточки «Марки»).
5. Фото доноров (26+ штук) — есть ли, для апгрейда карточек моделей.

**Плейсхолдеры:** адреса (два), графики (пока Пн–Сб 9:00–18:00), телефон, реквизиты ФОП, годы для Crafter / Pajero Wagon / Terracan / ML W163 / X5 E53 / Fiat Titano, реальные количества по категориям, популярные товары по моделям, названия в чипах «Часто шукають», фото команды, фото ворот, фото категорий с обтравкой (9 PNG), логотипы брендов в цвете, логотип monoPay.

## 2. Визуальные решения

**Цвета:** primary #E0001B. Нейтральная шкала — холодные серые. Светлый фон #F6F6F6. Статусный зелёный (success) — точка «В наявності», теги в блоке преимуществ. Чистые #000/#FFF не используются.

**Где разрешён primary:** кнопки действия, активный таб/подчёркивание, бейдж скидки, бегущая рамка акционной карточки, иконки преимуществ в карточке покупки, маркер на карте, галочки «перевірено» в иллюстрациях, обводка круглой стрелки. **Исключения, зафиксированные как осознанные:** две красные карточки в «DLSAuto в цифрах» (вариант 2); красное свечение диска и луч на первом экране «Про компанію». Больше декоративного primary не добавлять. Primary на hover не используется (hover — нейтральный). Полной красной заливки блоков нет.

**Логотипы брендов:** монохромные везде (метки карточек, чипы, мега-меню), **кроме** плиток брендов в блоке «Деталі для вашого авто» — там цветные.

**Кнопки:** primary — заливка. Secondary — обводка primary, текст primary, hover подкладка 8 %. Tertiary — текст, подчёркивание на hover. Белая кнопка с тёмным текстом — только на тёмных/фото фонах. Без стрелок в тексте кнопок, если не оговорено. Размеры S / M / L.

**Круглая кнопка-стрелка** — круглая secondary: прозрачный фон, обводка 1px primary, иконка «→» primary, hover — подкладка 8 %. Два размера: S (в карточках моделей, мега-меню, пунктирных карточках) и XL (в крупных карточках категорий). На фото-фонах — белая с тёмной иконкой. Это один компонент — других круглых стрелок не создавать.

**Табы:** чипы-пилюли: неактивный — светлая заливка, активный — тёмная заливка с белым текстом. Применено в «Нові надходження», рекомендациях товара, сравнении. Исключение — табы первого экрана главной на тёмном фоне.

**Плитка бренда** (селектор в «Деталі для вашого авто»): белая, тонкая рамка, цветной логотип + название под ним; hover — рамка neutral-900, без тени; активная — заливка neutral-900, белый монохромный логотип, без тени и подъёма. Один язык: «тёмное = выбрано».

**Типографика:** заголовки обычным регистром, uppercase только eyebrow. H2 секций — один токен и вес (semibold) везде. Нумерованные подзаголовки шагов («01 Оберіть марку») — стиль из «Чому розбірка, а не магазин». Размеры в промптах — токенами, не px.

**Вертикальные отступы (правило страницы):** видимое расстояние между контентом соседних секций — space-96 на десктопе, space-64 на мобайле, других значений нет. Для секций с собственным фоном на всю ширину: до края полосы, внутри полосы сверху и снизу, после полосы — то же значение. Первый экран — сразу под хедером. H2 → контент секции — space-32 (мобайл space-24); если есть H3 шага: H2 → H3 space-32, H3 → контент space-16.

**Иконки:** один линейный набор; автотематические кастомные: спідометр, гайковий ключ із галочкою, колісний диск, слід протектора, банківська картка, пикап (404). Красных плашек под иконками нет. Иконки «из набора по умолчанию» и эмодзи не используются.

**Запреты:** точки «·» перед числами; счётчики количества; упрощённые хедеры/футеры; дубли заголовков; текст поверх середины фото с серой пеленой; вырезы в углах карточек (пробовали — чужой элемент, отклонено); выдуманные сущности в макетах (категории, названия, цифры).

**Хедер и футер** идентичны на всех страницах. Хедер: тёмная верхняя полоса (в ней же переключатель uk/ru и, в сезон, место для баннера над шапкой) + белая основная (логотип DLSAuto, «Каталог ▾», поиск на всех страницах кроме главной, чип «Обрати авто», «Замовити дзвінок» secondary, избранное, сравнение, корзина с бейджами). При скролле вниз не закреплён, при скролле вверх появляется. Футер — два адреса (Запоріжжя, Дніпро).

## 3. Компоненты

**Карточка товара:** фото 1:1; сердце и весы на белых круглых плашках справа сверху, быстрый просмотр на hover; метка донора с мини-логотипом «Ranger 2006–2012» (без марки и близнеца, тултип), либо «Підходить на ваше авто» с зелёной галочкой; название в одну строку; «OEM …»; «В наявності, Дніпро» с зелёной точкой (город — в той же строке, без бейджей); цена + квадратная primary-кнопка корзины. Hover: подъём, тень, стрелки фото, «В кошик». Бейджи «Нове»/«Популярне» нейтральные, «−20%» primary + бегущая рамка (независимые поля). Слот под праздничную наклейку — отдельный, совместим с бейджем и рамкой (макет в бэклоге).

**Карточка модели** (блок «Деталі для вашого авто»): белая, фиксированная высота в ряду; название text-2xl semibold, годы, внизу «85 деталей» и круглая стрелка S. Без фото, без типа кузова, без чипа бренда. Формы слова: 1 деталь, 2–4 деталі, 5+ деталей. Пунктирная карточка «Усі моделі {Бренд}» — те же слоты (eyebrow «ЩЕ 4 МОДЕЛІ», текст в слоте названия, стрелка внизу справа), показывается только когда моделей больше трёх.

**Чип модели:** мини-логотип, название с годами, количество внутри справа, тонкая рамка; активный — тёмная заливка. Версия для тёмного фона: обводка neutral-600, текст neutral-50, hover заливка neutral-800.

**Строка модели** (индекс/меню): название слева, количество справа, тонкий разделитель, hover — светлая подкладка.

**Тост** (правый нижний угол), **корзина-панель** (мин. заказ 500 ₴, прогресс-бар, зелёный при достижении; у каждого товара мелко город), **быстрый просмотр** (модалка 50/50), **sticky buy bar** на странице товара (появляется, когда «В кошик» ушла за экран; по центру, не на всю ширину; учитывает хедер, появляющийся при скролле вверх).

**Мега-меню** (стиль Insta360): на всю ширину экрана, три колонки — марки (список с логотипами, активный подсвечен, hover меняет центр), модели (карточки без фото: название, «2005–2015 — 85 деталей», круглая стрелка S; последняя карточка пунктирная «Усі деталі Mitsubishi»), категории (строки с количеством, первые «Новинки» и «Популярне», внизу secondary «Усі категорії»). Без поля поиска внутри. Мобайл: полноэкранная панель, экран «Каталог» с аккордеонами «За маркою» / «За категорією».

**Карточка-документ** (блок преимуществ): светлая карточка — лейбл + бейдж слева, крупное значение справа, разделитель, три пары лейбл–значение, тёмная нижняя плашка с иконкой, текстом и зелёным тегом. Для карточек брендов пробовали — отклонено (данных мало, пусто).

**Слот сменяемых карточек** («Що ще ми робимо»): карточка фиксированной высоты, в которой по очереди показываются N карточек; автосмена каждые 7 с, пауза при hover и вне вьюпорта; кроссфейд, фото новой сходит с лёгкого увеличения, подпись с задержкой; индикатор прогресса в зоне подписи, клик переключает; при reduced-motion автосмены нет.

## 4. Главная — блоки и статус

1. Хедер — готов.
2. Первый экран — готов (тёмное фото, H1, табы «Підбір за авто»/«За номером або назвою», три поля + «Знайти деталь», «Популярні марки»). **Вариант B** на отдельной странице «Головна-B»: справа карточка подбора со stepper'ом, слева H1 + стеклянные плитки-стати: «1 200+ деталей», «4.8 на Prom.ua», «до 15:00 — відправка в день замовлення», «до 60 днів гарантії».
3. **DLSAuto в цифрах** — вариант 2: светлый фон, 4 карточки в шахматном порядке, чёрные и красные через одну, вырез сверху с автоиконкой, hover-анимации. Тексты (без дублей с первым экраном): ДОСВІД 4+ «Роки на ринку: самі купуємо, розбираємо і продаємо»; ЗАМОВЛЕННЯ 5 000+ «Відправлених деталей за рік по всій Україні»; МАРКИ 15 «Марок, основа — пікапи та позашляховики»; ПЕРЕВІРКА 100 % «Кожна деталь перевірена на стенді або на авто, дефекти обведені». 4. **Категорії запчастин** — два варианта на канвасе. **A** (базовый, готов): 5×2 чистых белых карточек с фото детали на белом, десятая «Усі категорії». **B** (в работе, для сравнения): светлые карточки с крупным обтравленным фото (фото доминирует), сетка с широкими карточками (одна категория-лидер «Двигуни» 2 колонки, широкая тёмная «Усі категорії»), под названием количество, круглая стрелка XL. В тёмной карточке — лейбл «Часто шукають» и чипы названий деталей (ведут в поиск; названия — плейсхолдер до топ-10 от клиента). Промежуточные варианты (тёмные карточки с вырезом в углу, мелкое фото) — отклонены.
5. **Деталі для вашого авто** (бывш. «Підбір за моделлю») — готов, заменил карточки брендов. H2 «Деталі для вашого авто», без кнопки в шапке. Шаг «01 Оберіть марку»: плитки брендов 8 в ряд × 2 ряда (16), активная — тёмная; по умолчанию Mitsubishi. Шаг «02 Моделі {Бренд}»: фиксированная сетка 4 колонки, карточки моделей (см. §3), не растягиваются; до 3 моделей + пунктирная «Усі моделі» только при >3; у брендов с 1–2 моделями — 1–2 карточки, остальное пусто. Переключение — opacity 150 мс без изменения высоты. Внизу строка «Не знайшли своє авто? Запитати менеджера» (tertiary). Мобайл: плитки — горизонтальный скрол, карточки в одну колонку. Отклонено: сетка карточек брендов со строками моделей, карточки-документы, силуэты авто (не отличают поколения, 26+ иллюстраций), чипы брендов, кнопка «Показати всі марки».
6. Нові надходження — готов, табы-пилюли по категориям; наполняется автоматически 15 самыми новыми в наличии.
7. **Послуги** — на канвасе варианты A (рекомендован) и B, см. v3. Решение не менялось.
8. Запчастини на пікапи — готов (чипы с логотипами, перенос в 2 строки, слайдер). Товары — по типу кузова модели + ручное закрепление.
9. Запчастини на позашляховики — готов, 1:1.
10. Перевіряємо перед продажем — видео 4:5 — готов.
11. Часті питання — готов (6 аккордеонов).
12. Відгуки — готов; только собственные отзывы сайта с модерацией, средняя считается; рейтинг Prom — статичное число со ссылкой.
13. **Преимущества над футером** — карточки-документы: «Відправка», «Оплата», «Гарантія», см. v3.
14. Футер — готов (смуга для СТО). Добавить второй адрес.

**Страница «Головна-B»:** хедер, первый экран B, «DLSAuto в цифрах» вторым, далее блоки 4–13 копией с «Головної», футер. Отступы по правилу §2.

## 5. Другие страницы

**Каталог** — готов: карточки категорий сверху, 5 колонок (1-я sticky-фильтры), чипы активных фильтров, сортировка, «Показати ще 20». Фильтры без перезагрузки, URL меняется. Фильтра по городу нет. В карточках — «В наявності, {місто}». Страницы марки и модели — тот же каталог с включёнными фильтрами.

**Результати пошуку** — промпт готов: каталог 1 в 1 с отличиями: H1 «Результати за запитом «…»» + «Знайдено N деталей», сортировка по релевантности по умолчанию, под заголовком чипы разбора запроса (марка/модель, категория, слово; те же чипы, что активные фильтры, снимаются крестиком; чип авто при выбранном авто), точный OEM → сразу на товар, ноль результатов → заголовок «За запитом «…» нічого не знайшли», три подсказки, форма «Запитати про деталь» (из «Контакти», запрос подставлен) и «Нові надходження»; проданная деталь с точным совпадением — первой с меткой «Продано» и secondary «Запитати аналог».

**Товар** — готов: галерея, правая колонка (метка + «Перевірити сумісність», H1, OEM с копированием, две плашки, карточка покупки: цена, «В кошик» + сердце + весы, 4 преимущества; «В наявності, Запоріжжя»), «Стан деталі», «Доставка» столбиком (НП / Delivery / Самовивіз с адресом пункта, где лежит деталь + плашка условий), «Приймаємо», «З цим купують». Ниже: рекомендации с табами «Ще з цього авто» / «Альтернативи» / «На ваше авто»; «Відгуки»; «Ви дивилися»; sticky buy bar. Характеристики и полное описание — не сделаны.

**Чекаут** — готов + правка: у «Самовивіз» список пунктов (Запоріжжя, Дніпро; масштабируется), по умолчанию пункт, где больше деталей заказа; если часть деталей в другом пункте — одна информационная строка («2 деталі зараз у Запоріжжі — привеземо на цей пункт, замовлення буде готове через 1–2 дні» — текст плейсхолдер до ответа клиента), без дробления заказа; у товаров справа мелко город. НП и Delivery — без изменений.

**Обране** — готов (ссылка на список, «Продано», «Ще на ваше авто»), в карточках город. **Порівняння** — готов, в карточках город.

**Про компанію** — готов, с правками: первый экран — диск нарисован идеальными окружностями в SVG с несимметричными элементами (вентиляционные прорези, 5 отверстий), наклон через CSS perspective + rotateX, вращение rotateZ ~24 с/оборот, свечение отдельным неподвижным слоем, без фильтров в кадре, стоп вне вьюпорта и при reduced-motion. «DLSAuto в цифрах» v2 (тексты как на главной). «Чому розбірка, а не магазин». «Шлях деталі». «Команда і цех». **«Що ще ми робимо»** — переделан: шапка — H2 слева, короткий текст справа (верх по верху H2); ниже две карточки 1:2 высотой 600 px: слева слот сменяемых карточек с двумя послугами (фото на всю карточку, подпись внизу на градиенте: квадратная плашка с кастомной иконкой, название, строка описания), справа видео (постер cover, play по центру, клик — модалка 16:9, та же подпись «Наш цех і двір»). Пригон авто карточкой не представлен — при необходимости третья карточка в слот. «Відгуки». CTA-блок текстовый. Текст «Усе — в одному дворі в Запоріжжі» и «авторозбірка в Запоріжжі» — переписать после ответов про Днепр.

**Контакти** — промпт готов, макет не проверен; обновить под два пункта: два адреса, два графика, два маркера, статус «Зараз відкрито» по каждому — ждёт данных клиента.

**Політика конфіденційності / Оферта** — одинаковой структурой (sticky-содержание), реквизиты ФОП на оферте. **404** — промпт готов.

## 6. Как работать

1. В новом чате прочитать DESIGN_RULES.md, этот файл, DESIGN_TOKENS.md; сверить разделы 4–5 с канвасом, сообщить расхождения.
2. Новые блоки — из существующих компонентов и токенов. Не создавать второй вариант карточки, чипа, таба, тоста, круглой стрелки.
3. Готовое не менять без просьбы. Варианты «для сравнения» ставить под текущим, не вместо.
4. Хедер/футер на новой странице — копия главной.
5. Размеры — токенами. Если в запросе px — ближайший токен.
6. **Промпты для Claude Design** — в отдельном копируемом блоке, на украинском. Задавать цель и рамки (компоненты, токены, запреты), не перечислять размеры и стили — пусть креативит внутри системы. Исключение — когда нужна точная правка конкретного значения.
7. Комментарии в чате — коротко, по-русски: почему так, что проверить.
8. Не выдумывать сущности для макетов (категории, модели, цифры, названия деталей) — брать из этого файла; чего нет — помечать плейсхолдером и записывать в вопросы клиенту.
9. После макета — чеклист из DESIGN_RULES.md §10.
10. Анимации — только transform/opacity, без SVG-фильтров в кадре; прототип не должен лагать на демо.

## 7. Дизайн-бэклог

- Праздничный режим: состояния карточки товара с наклейкой (тыква / шапка эльфа / писанка) рядом с бейджем и рамкой; глобальный эффект при открытии (летучие мыши, снег) — лёгкий, один раз за сессию.
- Баннер над шапкой: полоса над тёмной полосой хедера, текст + ссылка + закрытие, привязка к сезону/датам; варианты фона в рамках системы.
- Контакти под два пункта выдачи.
- Товар: характеристики и полное описание.
- Категорії: довести вариант B или закрепить A.
- Переключатель uk/ru в тёмной полосе хедера, страницы `/ru`.
- Карточки моделей с фото доноров — когда клиент даст фото (включается на весь блок разом).
