# Базовые правила веб-дизайна

Этот документ — обязательный свод правил для любого макета в проекте. Он не задаёт конкретные цвета и шрифты (их определит дизайн-система позже), он задаёт дисциплину: как принимаются и применяются визуальные решения. Правила приоритетнее собственных предпочтений генерации. Если запрос пользователя противоречит правилу — спроси, прежде чем нарушать.

Главный принцип: **каждое визуальное решение принимается один раз и применяется везде одинаково.** Макет выглядит дорого не из-за эффектов, а из-за последовательности.

---

## 0. Порядок работы

Перед первым экраном любого проекта зафиксируй токены и выведи их коротким блоком в ответе:

- типографическая шкала (размеры, веса, межстрочные)
- шкала отступов
- палитра: primary, нейтральная шкала, акцент (если есть), семантические цвета
- радиусы, тени, толщина бордеров
- размеры кнопок и полей ввода
- ширина контейнера и сетка

Дальше все экраны строятся только из этих токенов. Новое значение добавляется, только если ни одно существующее не подходит — и тогда оно добавляется в список токенов, а не используется локально.

После генерации каждого экрана проведи самопроверку по чеклисту из раздела 10.

## 1. Типографика

- Один шрифт для всего. Максимум два: один для заголовков, один для текста. Декоративный третий — только по явной просьбе.
- Шкала размеров фиксирована и содержит не более 6–7 ступеней. Пример для десктопа: 56 / 40 / 28 / 20 / 18 / 16 / 14. Для мобильного — своя шкала, тоже фиксированная. Любой текст на макете имеет размер из шкалы.
- Заголовки одного уровня имеют одинаковый размер, вес, цвет и межстрочный интервал на всём сайте. Заголовок секции на главной равен заголовку секции на любой другой странице.
- На странице один H1. Заголовки секций — H2, одинаковые во всех секциях. Подзаголовки внутри секций — H3. Не прыгать через уровни.
- Веса: максимум три (например regular, medium, semibold или bold). Не использовать light на светлом фоне для основного текста.
- Межстрочный интервал: 1.1–1.25 для крупных заголовков, 1.4–1.6 для основного текста. Чем крупнее шрифт — тем плотнее.
- Длина строки основного текста: 55–75 символов. Абзац текста не растягивается на всю ширину контейнера — у него есть max-width.
- Цвет текста — не более трёх уровней: основной, вторичный, приглушённый (подписи, плейсхолдеры). Все три — из одной нейтральной шкалы.
- Выравнивание текста внутри секции единое. Центрирование — только для коротких заголовков и подзаголовков в один-два ряда. Абзацы по центру не выравниваются.
- Uppercase с разрядкой (letter-spacing) — только для мелких лейблов (eyebrow, теги, категории), не для заголовков и кнопок.
- Трекинг крупных заголовков слегка отрицательный (−0.01 … −0.03em). Мелкий текст трекинг не трогает.

## 2. Отступы и сетка

- Базовая единица 8px (4px для микроотступов внутри компонентов). Шкала: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128. Отступов вне шкалы не существует.
- Вертикальный внутренний отступ секции одинаков у всех секций страницы (например 96px десктоп / 64px мобильный). Не делать одну секцию «воздушной», а соседнюю «плотной» без причины.
- Расстояние между заголовком секции и её контентом одинаковое во всех секциях. Расстояние между подзаголовком и заголовком — одинаковое.
- Принцип близости: связанные элементы ближе друг к другу, чем несвязанные. Отступ внутри карточки меньше, чем отступ между карточками. Отступ между карточками меньше, чем отступ между секциями.
- Одинаковые элементы в ряду разделены одинаковым промежутком. Сетка карточек имеет один gap по горизонтали и вертикали.
- Один контейнер с фиксированной max-width для всего сайта (например 1200 или 1280px). Все секции выровнены по его краям. Full-bleed фон допустим, контент внутри — всё равно в контейнере.
- Сетка 12 колонок с фиксированным gutter (24px). Элементы выравниваются по колонкам, а не ставятся на глаз.
- Левый край текста, кнопок, изображений внутри одной колонки совпадает. Разъехавшиеся на 2–4 пикселя края — брак.

## 3. Цвет

- Один primary. Одна нейтральная шкала из 8–10 ступеней одного семейства (все серые либо тёплые, либо холодные — не смешивать). Один опциональный акцент. Четыре семантических: success, warning, error, info. Всё. Больше цветов не существует.
- Пропорция 60/30/10: нейтральный фон и поверхности — большинство, нейтральный текст и вторичные элементы — треть, primary — не более десятой части видимой площади.
- Primary используется только для действий и ключевых акцентов: главная кнопка, активное состояние, ссылки, одна выделенная цифра. Не для фонов секций, не для декоративных плашек, не для иконок подряд.
- Чистый чёрный #000 и чистый белый #FFF для текста и больших фонов не используются — только ступени нейтральной шкалы. Исключение: когда дизайн-система это задаёт явно.
- Контраст текста к фону — не ниже WCAG AA (4.5:1 для основного текста, 3:1 для крупного и для UI-элементов).
- Фоны секций чередуются не более чем между двумя-тремя значениями нейтральной шкалы. Каждая секция в своём цвете — ошибка.
- Градиенты, свечения, стеклянные эффекты, цветные тени — запрещены по умолчанию. Допускаются, только если заложены в дизайн-систему как осознанный приём и применяются по одному правилу везде.
- Текст поверх изображения — только с оверлеем или на области изображения с гарантированным контрастом.

## 4. Кнопки и CTA

- Три уровня иерархии: primary (залитая), secondary (контурная или нейтральная заливка), tertiary (текстовая/ссылка). У каждого уровня один стиль на весь сайт.
- Фиксированные высоты по размерам: например L 56px, M 48px, S 40px. Высота кнопки, поля ввода и селекта одного размера совпадают.
- Одинаковые по смыслу действия имеют одинаковый размер, стиль и формулировку везде. «Добавить в кошик» в карточке каталога и на странице товара — одна и та же кнопка. «Замовити дзвінок» в шапке и в футере — одна и та же.
- В одной видимой зоне экрана — одна primary-кнопка. Рядом с ней может стоять secondary. Две primary рядом — ошибка.
- Текст кнопки — глагол или действие, 1–3 слова. Не «Подробнее», а «Дивитись каталог». Не «OK», а конкретное действие.
- Горизонтальный padding кнопки пропорционален высоте (примерно 0.5× высоты с каждой стороны). Кнопки не растягиваются на всю ширину на десктопе, только на мобильном при необходимости.
- Радиус кнопки совпадает с радиусом полей ввода и берётся из общей шкалы радиусов.
- Иконка в кнопке одного размера с кеглем текста (16–20px), отступ от текста 8px.

## 5. Компоненты и детали

- Радиусы: не более трёх значений (например 4 / 8 / 16 или 0 / 8 / 24). Все карточки — один радиус. Все кнопки и инпуты — один радиус. Вложенный элемент имеет радиус меньше внешнего или равный ему.
- Тени: максимум два уровня (например для карточек на ховере и для модальных/дропдаунов). Тень мягкая, низкой непрозрачности, с одним направлением. Тени «для красоты» на всех карточках — ошибка.
- Бордеры: одна толщина (1px) и один цвет из нейтральной шкалы на весь сайт. Не смешивать бордеры и тени как способ отделить карточку — выбрать одно.
- Карточки одного типа идентичны: один padding, одно расположение элементов, одна высота в ряду. Заголовки карточек в ряду выровнены по одной линии даже при разной длине текста.
- Иконки: один набор (например Lucide), одна толщина штриха, фиксированный размер на контекст (16 в тексте, 20 в кнопках, 24 отдельно стоящие, 32–48 в фичах). Эмодзи вместо иконок не используются.
- Изображения внутри одного блока имеют одинаковые пропорции (aspect ratio) и одинаковую обработку. Фото товаров — на одинаковом фоне.
- Формы: лейбл над полем, одинаковое расстояние лейбл–поле–подсказка во всех формах. Поля одной формы одной высоты. Обязательные поля помечены единообразно.
- Таблицы и списки: одинаковая высота строк, выравнивание чисел по правому краю, текста — по левому.

## 6. Композиция и иерархия

- На каждом экране один главный элемент, который считывается первым. Если непонятно, куда смотреть — иерархии нет.
- Иерархия строится в первую очередь размером, весом и отступами, во вторую — цветом. Не выделять всё подряд.
- Количество паттернов раскладки секций ограничено: например «текст слева — медиа справа», «заголовок по центру — сетка карточек», «full-width медиа». Три-четыре паттерна на сайт, повторяются.
- Воздух — не пустота, а инструмент. Между секциями и вокруг ключевых элементов воздуха много. Внутри плотных блоков (таблицы, фильтры, карточки товаров) — плотно и ровно.
- Первый экран не перегружен: заголовок, подзаголовок, одно-два действия, одно медиа или ключевой функциональный блок. Не пять УТП, три кнопки и слайдер одновременно.
- Чётное количество одинаковых элементов в ряду — 2, 3, 4 или 6. Ряд из пяти карточек в 4-колоночной сетке с одной «сиротой» — ошибка.

## 7. Контент в макете

- Никакого lorem ipsum. Текст на языке проекта, реалистичной длины, по смыслу. Заголовки — настоящие формулировки, а не «Заголовок секции».
- Цифры, цены, названия, артикулы — правдоподобные для предметной области. Фото или плейсхолдеры с правильными пропорциями и описанием содержимого, а не серые прямоугольники с крестом.
- Длина текста соответствует реальности: название товара может быть в две строки, адрес — длинным, имя — коротким. Макет должен выдерживать это, а не рассчитывать на идеальные данные.
- Есть состояния: hover и focus для интерактивных элементов, disabled, loading, пустое состояние для списков, ошибка для полей. Хотя бы ключевые из них показаны или описаны.

## 8. Адаптивность

- Мобильная версия — не уменьшенный десктоп. Своя типографическая шкала, свои отступы секций, кнопки на всю ширину, сетки схлопываются в 1–2 колонки.
- Минимальная область касания 44×44px. Расстояние между соседними тач-элементами не меньше 8px.
- Порядок блоков на мобильном осмыслен: главное действие доступно без скролла или закреплено.

## 9. Что запрещено по умолчанию

- Размеры шрифта вне шкалы. Заголовки одного уровня разного размера в разных секциях.
- Кнопки трёх разных высот для одного действия.
- Несколько семейств серых в одном макете.
- Градиенты, glow, glassmorphism, цветные тени, бесконечные скругления — «по умолчанию, потому что красиво».
- Каждая секция со своим фоновым цветом.
- Тени на всём. Бордер плюс тень на одной карточке.
- Смешанные наборы иконок, эмодзи вместо иконок, иконки разной толщины штриха.
- Текст по центру абзацами. Строки по 120+ символов.
- Lorem ipsum, серые плейсхолдеры с крестом, «Заголовок», «Описание», «Кнопка».
- Декоративные элементы без функции: абстрактные блобы, случайные линии, частицы.
- Чистый #000 текст на чистом #FFF фоне.
- Visual noise: бейджи, лейблы, иконки и подписи на каждом элементе карточки одновременно.

## 10. Чеклист самопроверки после каждого экрана

Проверь и честно отметь нарушения, прежде чем показывать результат:

1. Все размеры текста — из шкалы? Заголовки одного уровня одинаковы во всех секциях?
2. Все отступы — из шкалы? Вертикальный отступ секций одинаков?
3. Левые края внутри колонок совпадают?
4. Цветов не больше, чем в палитре? Primary занимает ≤10% площади?
5. Одинаковые по смыслу кнопки — одного размера и стиля? Одна primary на зону?
6. Радиусы — из трёх значений? Тени — максимум двух уровней?
7. Иконки — один набор, один размер на контекст?
8. Контент реалистичный, на языке проекта?
9. Один H1? Иерархия считывается за секунду?
10. Есть ли что-то, что добавлено «для красоты» и не несёт функции? Убрать.

Если нарушение осознанное и оправданное — назови его и объясни зачем. Если нет — исправь до показа.
